# MyFontCraft

自分だけのオリジナルフォントを作れるWebサービス。

## 特徴

- **かんたん**: テンプレートを印刷して手書き → スキャンするだけ
- **プライバシー安心**: すべての処理がブラウザ内で完結。画像がサーバーに送られません
- **無料**: ユーザー登録不要、完全無料

## 使い方

### 1. テンプレートを印刷する

「1. テンプレート」からPDFをダウンロードして印刷します（約51ページ）。

### 2. 手書きで記入

各マスに文字を書きます。

- 1文字につき2マスあります（書き直し用。両方書いた場合はデフォルトで右側のマスが採用されます）
- 最低1つ書けばOK
- 両方書いて左側を採用したい場合は、左マス下のチェック欄に✓をつけてください
- チェック欄は任意です（✓ を書かなくてもOK）

### 3. スキャン or 撮影

- スキャナーでスキャン、または
- スマホで撮影

斜めに撮っても自動補正されます。事前の画像加工は不要です。

### 4. フォントを作成する

「2. フォント作成」からスキャンした画像をフォルダごと、またはZIPにまとめてアップロードします。

- ファイル名やフォルダ階層は自由です
- ページの識別はQRコードで自動的に行います

処理が完了すると、フォントファイル（.ttf）をダウンロードできます。

## 対応文字

- ひらがな（83文字）
- カタカナ（87文字）
- 英数字・記号（102文字）
- 常用漢字（2,136文字）

## 動作環境

モダンブラウザ（Chrome, Firefox, Safari, Edge）

## 不具合の報告

うまく動かない場合は [GitHub Issues](https://github.com/kako-jun/my-font-craft/issues) から報告してください。ページ最下部のフッターに表示されている `build xxxxxxx (YYYY-MM-DD)` を添えていただけると版が特定でき、調査がスムーズになります。エラー発生時のトーストメッセージにも `[build: xxxxxxx]` が付きます。
